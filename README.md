# 💻 Projetos em Linguagem C

Repositório destinado ao armazenamento e à organização dos meus projetos desenvolvidos utilizando a linguagem de programação **C**.

Aqui serão publicados projetos práticos criados ao longo da minha jornada de aprendizado, com o objetivo de aplicar conhecimentos de programação, desenvolver soluções e aprimorar minhas habilidades técnicas.

## Tecnologias e ferramentas

- **Linguagem:** C
- **Compilador:** GCC
- **Editor:** Visual Studio Code
- **Sistema operacional:** Linux (Ubuntu)

## Objetivos

- Desenvolver projetos utilizando a linguagem C.
- Aplicar conceitos de lógica de programação.
- Aprimorar habilidades de resolução de problemas.
- Explorar diferentes recursos e funcionalidades da linguagem.
- Documentar minha evolução por meio dos projetos desenvolvidos.
